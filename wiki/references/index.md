# References

External material and the models this wiki adopts. `references/` is OKF's own
convention (§6) for exactly this.

# Formats adopted

* [Open Knowledge Format (OKF) v0.2](okf.md) - The frontmatter format with trust signals that this bundle uses.
* [LLM Wiki](llm-wiki.md) - The organising pattern this wiki implements, and the four things that keep it from rotting.

# The distinction that matters

**OKF is a published specification** from Google Cloud, with a version number and a
conformance rule. The page here summarises it, and the canonical spec wins on any
conflict. **LLM Wiki is not a specification at all**: it is the name for a pattern we
practise in this repository. Its page says so in the first line, so nobody cites it as
though it were an external standard.

Both pages carry `status: draft` and no `verified` entry, which under OKF's own rules
puts them in the `unverified` tier. That is accurate: an agent wrote them and no person
has checked them line by line yet.
