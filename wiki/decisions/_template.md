# NNNN. Short imperative statement of what was decided

## Context

What forced a decision. The constraint, the deadline, the bill, the outage, the thing
that stopped working. Write it so someone who was not there understands the pressure,
not just the options.

## Options considered

| Option | For | Against |
|---|---|---|
| The one chosen | | |
| The strongest alternative | | |
| The obvious one that was rejected | | |

## Decision

What was chosen, stated plainly. If the choice was conditional ("this, until X"), say
what X is, because that is the trigger to revisit.

## Consequences

What this costs, what it locks in, and what becomes harder. A decision with no listed
downside was not really a decision.

## Revisit when

The concrete signal that should reopen this: a price threshold, a scale number, a
dependency reaching end of life. Leave it empty only when the decision is permanent.
